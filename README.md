# 🛡️ RakshaNet – Smart Safety & Scam Detection App

RakshaNet is a mobile safety application built using React Native (Expo) that helps users stay safe by detecting **spam/scam activities**, enabling **SOS alerts**, and providing **real-time location and weather updates**.

---

## 🚀 Features

* 🚨 **SOS Emergency System**
  Instantly trigger alerts during dangerous situations.

* 📍 **Live Location Tracking**
  Share real-time location for quick assistance.

* ⚠️ **Spam & Scam Detection**
  Identify suspicious activities/messages to protect users from fraud.

* 🌦️ **Weather Information**
  Real-time weather updates based on user location.

* 🎥 **Emergency Video Recording**
  Record surroundings during SOS situations.

* 📱 **Clean UI/UX**
  Simple and responsive interface for quick access in emergencies.

---

## 🛠️ Tech Stack

* **Frontend:** React Native (Expo)
* **Language:** JavaScript
* **APIs Used:**

  * OpenWeather API
* **Other Tools:**

  * Context API (state management)
  * Expo Vector Icons
